# BPL 예제 모델

- `aging_system.bpl`: 노화세포 상대 부담 `x`, 면역 제거 비율 `i`, 리소좀 분해능력 `L`을 시간에 따라 계산하고 원식·후보식을 함께 출력합니다.
- `senescence_immune_lysosome.bpl`: 노화세포, 면역 제거, 단백질 손상, 리소좀 분해의 집단 반응망을 모델링합니다.
- `tissue_repair.bpl`: 조직 손상, 회복 세포 집단, 염증 신호의 간단한 결합 동역학을 표현합니다.

모든 예제는 가상의 값으로 만들어진 소프트웨어 테스트 모델입니다. 실제 인체 생물학을 정량적으로 대표하지 않습니다.
